[h1]Backing & Lane Prediction - ATS[/h1]
[b]Subscribing alone shows nothing.[/b] The lines are drawn by a small plugin that Steam cannot install: [b][url=https://github.com/robertBojor/Reverse-Overlay---Guide-Lines---ATS/releases/latest]download the plugin here[/url][/b], exit the game and run [i]Install.bat[/i]. Already have it? [b]0.5.0 is out[/b] with a new installer that also covers Euro Truck Simulator 2.

[b]Now also for ETS2:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3823038411]Backing & Lane Prediction - ETS2[/url]. The same plugin works in both games.

Backup-camera style guide lines for reversing, and a forward line for lane position. While you are in reverse, two lines are drawn on the ground from the rear corners of your trailer (or truck, when bobtail) along the path it will actually take:

[list]
[*][b]Red[/b] for the first 3 m, [b]yellow[/b] to 8 m, [b]green[/b] out to 15 m, with ticks where the colour changes
[*]Real objects in the world, so they show in [b]every camera and in the mirrors[/b]
[*]Follows your [b]actual wheel angles[/b] (different steering locks, lift axles and multi-steer trucks)
[*]Single trailers, doubles and triples; self-steering trailer axles included
[*]Distances and line height adjustable in a settings file
[/list]

[h2]Forward line for lane position[/h2]
In a forward gear, a light, see-through [b]blue line[/b] runs on the road from the middle of your front axle along the path the truck will take, curving with the steering. It is 25 m long when slow and up to 40 m at highway speed, and at speed it follows how the truck is actually turning, so it stays true on long bends. Keep it in the middle of your lane. Trailers are ignored, because they follow inside the truck's path.

[h2]Keyboard shortcut: Ctrl+Shift+F9[/h2]
Each press moves to the next mode (only while the game window has focus):
[olist]
[*][b]Forward line only[/b]
[*][b]Reverse lines only[/b]
[*][b]Both[/b]: the forward line in a forward gear, guide lines in reverse
[*][b]Nothing[/b]: everything hidden
[/olist]
The next press starts again at forward line only. Your choice is remembered between games; the very first start is on [b]Both[/b]. Another key can be set in the [i][hotkey][/i] section of the settings file.

[b]Updating?[/b] Steam updates this item on its own; run the new [i]Install.bat[/i] for the plugin. Coming from plugin 0.3.0 or older, the update is needed for the blue line. Older plugins keep working with this item.

Open source (MIT): read the full README, user guide and source code on GitHub before installing: [b][url=https://github.com/robertBojor/Reverse-Overlay---Guide-Lines---ATS]Backing & Lane Prediction on GitHub[/url][/b]

[h2]Settings and troubleshooting[/h2]
The plugin download includes a full user guide (User_Guide.md) with installation, settings, troubleshooting and what happens after game updates.

Settings: [i]Documents\American Truck Simulator\ats_reverse_overlay.ini[/i] (created on first start, changes apply while driving).
Log: [i]Documents\American Truck Simulator\ats_reverse_overlay.log[/i]. The first lines say whether the plugin found what it needs on your game version, and which mode the shortcut is in.

[list]
[*][b]No lines at all:[/b] check that the DLL is in [i]bin\win_x64\plugins[/i] and this mod is enabled, then press [b]Ctrl+Shift+F9[/b]: the mode may be set to show nothing.
[*][b]Log says "Could not create /model/rto_guides/line_blue.pmd":[/b] the mod is older than the plugin. Let Steam update this item, or update the local .scs.
[*][b]Plugin does not load at all:[/b] the DLL is not digitally signed yet; Windows Smart App Control or antivirus software may block it. See the user guide.
[*][b]After a game update:[/b] if the log says "engine functions missing", the lines switch themselves off until the plugin is updated. The game keeps running normally.
[/list]
